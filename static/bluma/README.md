# Bluma

Original AnkiQuest purple cow, generated with OpenAI `image_gen` on
2026-11-16. The tool did not expose its model identifier. Aki and
Ankilope supplied the illustration style; Bluma has her own cow silhouette,
cream muzzle and eye patches, lavender forelock, ivory horns, indigo scarf
and brown flashcard satchel. She is not based on a commercial cow mascot.

The eight transparent 1254 px masters supply face, asleep (`sleeping`),
happy (`celebrate`), streak, sad, hopeful, frozen and neglected poses.
The old tinted Ankilope artwork is preserved.

[Review and provenance](../../docs/branding/bluma-core-2026-11/README.md)
include all 24 prompts, the selections, cleanup measurements and reusable
style/pose prompts. Aldana has not yet approved the appearance.

Export with `cargo run -p ankiquest-xtask -- export-addon-art` and
`cargo run -p ankiquest-xtask -- export-android-art <android-checkout>`.
Pose selection and unlock activation belong to the companion follow-up.
