# Bluma

Canonical core masters for companion id `cow`: face, asleep, happy,
streak, sad, hopeful, frozen and neglected. All are 1254 px transparent
PNGs, byte-identical to the preserved originals under `../bluma/`.
The asleep and happy originals used the names sleeping and celebrate.

OpenAI `image_gen` generated the original images; the model identifier
was not exposed. [Provenance and prompts](../../docs/branding/bluma-core-2026-11/README.md).
Hill approved the appearance; Aldana's final approval remains pending.
The other contributor owns pose selection and unlock activation.
